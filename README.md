# ESP32 กริ่งโรงเรียนดังเองตามคาบเรียน

โค้ดประกอบคลิปของ **K iTech Review** (TikTok) / **Kham iTech Lab** (YouTube · Facebook)

ESP32 ดึงเวลาจากอินเทอร์เน็ต แล้วสั่งรีเลย์ให้กริ่งดังตามตารางคาบ เพิ่มโมดูลนาฬิกา DS3231 ได้ เผื่อวันที่เน็ตล่ม กริ่งก็ยังดังตรงเวลา

## ของที่ต้องใช้

- บอร์ด ESP32 (DevKit V1)
- รีเลย์โมดูล 1 ช่อง 5V (หน้าสัมผัสรับ 220V 10A)
- โมดูลนาฬิกา DS3231 พร้อมถ่าน (ไม่บังคับ แต่แนะนำ)
- อะแดปเตอร์ 5V 1A เลี้ยงบอร์ด

## ต่อวงจร

| อุปกรณ์ | ขา | ESP32 |
| --- | --- | --- |
| รีเลย์ | IN | GPIO 26 |
| รีเลย์ | VCC / GND | 5V (VIN) / GND |
| DS3231 | SDA / SCL | GPIO 21 / GPIO 22 |
| DS3231 | VCC / GND | 3.3V / GND |

> ⚠️ ฝั่งกริ่ง 220V (ขา COM / NO ของรีเลย์) ให้ช่างไฟเป็นคนต่อ ห้ามต่อไฟบ้านเข้าบอร์ด ESP32 เด็ดขาด

## ติดตั้ง

1. ลงไลบรารี **RTClib** (by Adafruit) ใน Arduino IDE ถ้าไม่มี DS3231 ให้ตั้ง `USE_DS3231` เป็น `0`
2. คัดลอก `secrets.example.h` เป็น `secrets.h` แล้วใส่ชื่อและรหัส Wi-Fi
3. แก้ตารางคาบใน `BELL_TIMES` และวันที่ให้ดังใน `RING_ON_DAY`
4. เลือกบอร์ด ESP32 Dev Module แล้วอัปโหลด เปิด Serial Monitor (115200) ดูสถานะได้

## ปรับแต่ง

- `RING_SECONDS` ความยาวเสียงกริ่ง (ค่าเริ่มต้น 5 วินาที)
- `RELAY_ACTIVE_LOW` รีเลย์บางรุ่นทำงานเมื่อขาเป็น HIGH ให้เปลี่ยนเป็น `false`
- กริ่งดังไม่กี่ครั้งต่อวัน รีเลย์ธรรมดาก็พอ ไม่ต้องใช้ SSR
